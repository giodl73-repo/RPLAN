# RPLAN PITFALL Index

RPLAN uses PITFALL to preserve doctrine for neutral district-plan packages,
canonical hashes, context provenance, audit certificates, CLI verification, and
consumer boundaries across BISECT, RCOUNT, CROP, and future civic tools.

## Integration

- ROLES: `.roles/ROLE.md` covers plan-package stewardship, audit-certificate
  skepticism, and consumer-boundary review.
- VTRACE: RPLAN does not currently carry a repo-local VTRACE matrix; PITFALL
  entries cite specs, compatibility policy, wave docs, roles, and executable
  tests until a VTRACE slice exists.
- Tests: Rust tests, CLI certificate tests, public example verification, and
  RCOUNT downstream rehearsal are the evidence hooks for PITFALL entries.
