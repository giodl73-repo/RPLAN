# Corresponding source and original grant

The source ZIP contains **every tracked Git blob** at the build commit, plus a
mode/byte/SHA256 manifest. This includes the original Rust algorithms and tests,
all existing public fixtures/examples (including the repository's RCOUNT package
examples), native/companion locks, profile checks, browser source, recipes,
roles, policy and original MIT LICENSE. No tracked source is silently omitted.
Unknown caller files and local ignored caches are never included.

The source ZIP is a complete source snapshot, not a Git-history export. The
build record and license page link the exact full Git archive and repository.
Dependency/runtime notices and their software metadata are separately listed;
original grants remain in LICENSE and each notice. No license is replaced.

The build's RCOUNT compatibility rehearsal fetches an exact public first-party
Git commit into temporary build space. That consumer checkout is not mirrored
into this artifact; its source and original grant remain in RCOUNT. Cargo/npm
fetch pinned build dependencies. No new external dataset, private input, census
source, legal authority or user media is fetched for the public bundle.

Rebuild outside Git using BUILD.md. The source replay runs native/admission
tests, original CLI comparisons, the three pinned RCOUNT rehearsals and real
browser task/recovery cases. It claims behavior/semantic custody, not byte
identity between binaries compiled in different source directories/platforms.

Caller profile, timestamp, lineage, geometry/source hashes and supplied evidence
remain assertions. Native audit/certificate verification establishes only its
documented declared checks and identities, not law, fairness, authenticity,
publication approval, consumer adoption or completed BISECT migration.
